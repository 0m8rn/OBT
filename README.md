# OBSIDIA — redesigned website

## Upload to GitHub Pages or Hostinger

1. Extract this ZIP on your computer.
2. Upload the extracted files into the same folder as your current website. Replace index.html, style.css and script.js together.
3. Keep the names exactly as shown. Do not leave download suffixes such as index(2).html or style(3).css.
4. Also upload obsidia-sculpture.webp, obsidia-symbol.svg, obsidia-favicon.svg and obsidia-favicon.png into that SAME folder.
5. Wait for your normal GitHub Pages deployment, then refresh the page. CSS and JS use a v=3 cache-busting query.

No assets subfolder, build step, paid plugin or server is needed. The page can also be opened locally by double-clicking index.html.
